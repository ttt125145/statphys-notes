#### 标题

```markdown
# 1级标题
## 2级标题
### 3级标题
#### 4级标题
##### 5级标题
###### 6级标题
```

#### 段落和换行

回车		换段落

shift+回车	换行



#### 斜体和加粗

```
斜体，用*或_包裹文本：
*XXXXX*
_XXXXX_
加粗，用**或__包裹文本：
**XXXXX**
__XXXXX__
```

示例：*AAAAA* **AAAAA**



#### 引用块

> '>'（无需空格）开头，创建引用块
>
> 回车即创建引用块第二行
>
>> 继续用‘>’内嵌引用块
>>
>> 连续两个回车推出一层引用块
>>

#### 列表

无序列表

* 开头输入 *加空格
* 开头输入 +加空格
* 开头输入 -加空格
* 回车进入下一条目，回车两次退出

有序列表

1. 开头输入数字.加空格
2. 回车进入下一条目，回车两次退出

任务列表  <a name='任务列表'></a>

- [ ] 开头输入  - [ ]
- [X] 可以勾选完成与否
- [ ] 回车进入下一条目，回车两次退出 

#### 代码

**代码块**

输入```(这个键在左上角TAB上面，英文模式)并回车。

围栏右下角选择代码语言

```python
import numpy as np

arr1 = np.zeros((3,4,5))
print(arr1.shape)
```

**单行代码**

```python
#用`包裹内容：
`print()`
```



#### 链接

##### url链接

链接示例：[ttt125145](https://github.com/ttt125145)

```markdown
[框选文本](url)
```

##### 同文档内部链接

跳转到标题 ：

```markdown
[框选文本](#标题)
```

跳转到锚点：

```markdown
创建锚点：    在需要重定向到的位置加入 <a id='锚点名'></a>

链接锚点：    [框选文本](#锚点名)
```

示例：[任务列表](#任务列表) （只能在预览模式下点击）

##### 跨文档链接

```markdown
用相对路径作为链接： 
    同目录：    [框选文本](XXX.md#标题或锚点名)
    子目录：    [框选文本](XXX/XXX.md#标题或锚点名)
    上级目录：  [框选文本](../XXX.md#标题或锚点名)
```

#### 图片

###### 方式一


或直接截图粘贴

或直接从网页拖动

```html

```

#### LaTeX样式

Typora内嵌了LaTeX基础和一些宏包的样式

**公式内常用**

```
正体 \mathrm{内容}
粗体 \boldsymbol{内容}
粗斜 \mathbf{内容}
粗正体 \mathbf{\mathrm{内容}}	比如矩阵符号
花体 \mathcal{内容}		比如拉格朗日符号
```
